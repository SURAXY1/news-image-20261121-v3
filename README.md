# THE DAILY BLAST — news-image-20261121

One page, one day: the whole planet's news of Saturday 21 November 2026
set as a screaming tabloid front page — Russian missiles down inside
Poland, a Wall Street wipeout, the first Trump–Xi–Putin table, a World
Court genocide verdict, UK–EU mega-deals, the COP31 fossil-fuel vanish,
and a ticker of everything else that blew up.

The entry is a single pure-stdlib Python program (`main.py`). It draws
the page with its own hand-rolled 5×7 bitmap typeface on a raster
canvas and encodes the PNG itself with `zlib` — no Pillow, no network,
no clock, no randomness. Every run produces byte-identical output.

Run it:

```sh
python3 main.py   # writes entry.png (and /output/entry.png if present)
```
